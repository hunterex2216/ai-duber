# Archer AI (Cube AI) — Autonomous Multimodal Live Android Assistant

A fresh, clean, production-grade Android AI assistant built with **Kotlin** and **Jetpack Compose** featuring:

- **3D Holographic Particle Globe & Outside-Only 3D Floating Globe Button**:
  - Inside the app: Interactive 3D particle globe with high-amplitude real-time speaking & listening waves.
  - Outside the app: When exiting to the Home Screen or any other app, a draggable 3D Floating Globe Button with live voice waves automatically appears on screen.
- **Dedicated Real AI Image Studio (`🎨 ছবি তৈরি স্টুডিও`)**:
  - Auto-routes across **Nano Banana Pro** (`gemini-3-pro-image-preview`), **Nano Banana 2** (`gemini-3.1-flash-image-preview`), **Imagen 4 Ultra / Fast**, and **Gemini 2.5 Flash Image**.
  - Supports both Paid Gemini API Key and Main Gmail Account login.
- **Mandatory Ask-Before-Save Confirmation**:
  - Never saves generated images or code to any folder automatically; always asks the user first (`💾 হ্যাঁ, সেভ করুন` / `🗑️ না, বাদ দিন`).
- **Smart Auto-Memory & Super-Powerful Main System Self-Update**:
  - Automatically remembers important user facts and directives (`save_user_memory`).
  - Promotes any user-specified system upgrade directly into the Main Core System (`self_heal_or_update`).
- **Screen-First Verified Single Clicking & Intelligent Search Judgment**:
  - Inspects live screen coordinates before clicking (`1 click per step`) with zero redundant taps.
  - Intelligently distinguishes normal conversation from actual Play Store / YouTube search queries.
- **Vocal-Preserving Audio DSP**:
  - Crystal-clear Bangla, English, and Banglish speech recognition (300 Hz–3400 Hz vocal boost).
